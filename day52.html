呢個星期我哋做咗兩件大事：條件形四兄弟（と・ば・たら・なら）收尾，同埋授受表現由「物」升級到「動作」（あげる・くれる・もらう → てあげる・てくれる・てもらう）。

呢兩組文法係 N4 讀解同聽解嘅「方向感」核心：條件形決定前後件關係，授受決定邊個幫邊個。今日唔學新嘢，專心將呢兩組鎖死，順便補返上星期六（Day 45）因系統故障漏咗嘅條件形複習。

✅ 昨日造句答案（Day 51）

  • 題目：「私は道がよくわからなかったので、田中さんに駅まで案内して（　　）。」1. あげた　2. くれた　3. もらった　4. やった
  • 正解：3. もらった
  • 完整句子：私は道がよくわからなかったので、田中さんに駅まで案内してもらった。
  • 廣東話解釋：我唔識路，所以請田中帶我去車站（我受咗田中帶路嘅恩惠）。
  • 💡 解析：主語「私は」＝受惠者；做嘢嘅人「田中さん」用 に。受惠者做主語 → てもらう。
  • 💡 點解唔用 くれた：用 くれた 要掉轉鏡頭——「田中さんが私を駅まで案内してくれた」。原句主語已經寫死「私は」，所以只能配 もらった。
  • 💡 點解唔用 あげた：あげた＝「我帶田中去車站」，同前半句「我唔識路」直接矛盾。

🔁 核心文法大盤點

1️⃣ 條件形四兄弟——同一個「如果」，四種鏡頭

と（辭書形／ない形 ＋ と）→ 必然・恒常・自然現象・機械操作・路線

  • 春になると、桜が咲きます。（一到春天，櫻花就開。）
  • このボタンを押すと、お湯が出ます。（撳呢個掣就會出熱水。）
  • まっすぐ行くと、駅が見えます。（直行就會見到車站。）
  • ⚠️ 後件唔可以接意志・命令・依賴：✗ 駅に着くと、電話してください → ✓ 着いたら

ば（假定形：u 段 → e 段 ＋ ば）→ 假定條件，語氣最書面

  • お金があれば、旅行に行きます。（有錢就去旅行。）
  • 安ければ、買います。（平就買。）
  • 變法：書く→書けば／食べる→食べれば／する→すれば／来る→くれば／安い→安ければ／静かなら（ば）

たら（た形 ＋ ら）→ 完成之後／假定／發現

  • 家に着いたら、すぐ電話してください。（到屋企即刻打電話。）
  • 雨が降ったら、試合は中止です。（落雨就取消比賽。）
  • 窓を開けたら、雪が降っていた。（一開窗，原來落緊雪——發現用法）

なら（名詞／普通形 ＋ なら）→ 承接對方話題，再給判斷／建議

  • 京都へ行くなら、春がいいですよ。（去京都嘅話，春天最好。）
  • パソコンなら、駅前の店が安いです。（講到電腦，站前嗰間平啲。）

三秒判斷流程：

1
後件係命令・依賴・意志？→ 用 たら（或 ば），唔用 と。
2
講自然現象／機械／路線？→ と。
3
對方啱啱講咗個話題，你想接住講？→ なら。
4
強調「只要條件成立就一定…」嘅書面假定？→ ば。

2️⃣ 授受表現——兩層方向圖

第一層：物（畀嘢）

  • あげる：我／第三者 → 別人（私は田中さんに本をあげた）
  • くれる：別人 → 我／我家人（田中さんは私に本をくれた）
  • もらう：我／別人收（私は田中さんに本をもらった）

第二層：動作（幫手）

  • てあげる：我／第三者幫別人做（私は田中さんに日本語を教えてあげた）
  • てくれる：別人幫我／我家人做（田中さんは私に日本語を教えてくれた）
  • てもらう：我受人恩惠（私は田中さんに日本語を教えてもらった）
  • 實用句：〜てもらえますか＝「可以幫我…嗎？」（比 〜てください 婉轉）

鐵律：

  • 主語＝做嘢嘅人 → くれる（方向過嚟我）／あげる（方向出去）
  • 主語＝受惠嘅人 → もらう（做嘢嘅人用 に／から）
  • あげる 系唔好對長輩／上級用（改用 ていただく，Phase 3 學）

⚠️ 本週高頻盲點速查（測驗前必睇）

1
と ＋ 依賴：✗ 駅に着くと、電話してください → ✓ 着いたら
2
なら 當「之後」用：✗ 家に帰るなら、寝ます（想講「返到屋企就瞓」）→ ✓ 帰ったら
3
可能形助詞：✗ 日本語を話せます → ✓ 日本語が話せます
4
受惠者係我用 てあげる：✗ 田中さんは私に教えてあげました → ✓ 教えてくれました
5
てもらう 助詞：✗ 田中さんを教えてもらいました → ✓ 田中さんに／から
6
くれる 主語寫成我：✗ 私はあなたに教えてくれました → ✓ 教えてあげました

👂 聽讀複習：一分鐘短文（條件形＋授受混合）

> 明日は友だちの結婚式です。朝、天気がよければ、自転車で行きます。雨が降ったら、駅までバスで行って、電車に乗ります。会場に着いたら、まず受付で名前を書きます。スピーチをするなら、短いほうがいいと聞きました。友だちがスピーチの練習を手伝ってくれたので、もう大丈夫です。式が終わったら、みんなで写真を撮ってもらいます。

廣東話對譯：聽日係朋友嘅婚禮。朝早如果天氣好，我會踩單車去。如果落雨，就搭巴士去車站再轉電車。到咗會場，首先喺接待處寫名。聽講如果要致辭，短啲會好啲。朋友幫我練咗致辭，所以而家冇問題。儀式完咗之後，我會請大家幫我哋影相。

聽解要點：

  • よければ：形容詞 いい → よければ（ば 形・假定）
  • 降ったら／着いたら／終わったら：三個 たら 都係「完成之後」
  • するなら：承接「スピーチ」呢個話題，再給判斷
  • 手伝ってくれた：朋友幫我 → てくれる
  • 撮ってもらいます：我請人幫我影 → てもらう

朗讀任務：大聲讀兩次。每次見到 たら／なら／ば，用手指比方向：たら＝向前（做完先）／なら＝接住（承接話題）／ば＝鎖（條件鎖死）。

📥 答案與解析

Q1 → 2. 話せます

  • 可能形：話す（一類）→ 話せる → 話せます。可能形前面用 が（中国語が話せます）。
  • ✗ 話させます＝使役（「讓…講」）；✗ 話されます＝被動（「被講」）。

Q2 → 1. なら

  • 對方啱啱講「きれいな町」，用 なら 承接話題再給建議：「講到靚嘅城鎮，推介京都」。
  • ✗ と 後面唔可以接建議；✗ ば／たら 喺呢個語境會變成「如果係靚城鎮」，意思扭曲。

Q3 → 2. 着いたら

  • 後件係依賴（電話してください），所以唔可以用 と；たら＝「到咗之後」。
  • ✗ 着くと＋依賴＝文法錯；✗ 着くなら＝承接話題；✗ 着きながら＝同時進行。

Q4 → 2. くれた

  • 主語「先生が」＝給予者，接受者「私に」＝我 → くれる。
  • ✗ あげた＝我畀老師，方向反；✗ もらった 要換主語（私が先生にもらった）；✗ いただいた 係謙讓語，主語一定要係「我」。

Q5 → 2. くれました

  • 主語「田中さんが」＝做嘢嘅人，受惠＝我 → てくれる。
  • ✗ あげました＝我幫田中改，意思反；✗ もらいました 要寫「私が田中さんに直してもらった」；✗ やりました＝我幫（下輩／動植物）做。

📋 本週小結

1
と＝必然／恒常，後件唔可以係命令・依賴・意志。
2
ば＝假定形＋ば，最書面嘅「只要…就」。
3
たら＝完成之後／發現，後件最自由（命令、依賴、意志都得）。
4
なら＝接住對方話題再判斷，唔表示時間順序。
5
授受鐵律：主語做嘢 → くれる／あげる；主語受惠 → もらう。
6
あげる 系唔好對長輩用，Phase 3 會換成 ていただく／てくださる。
